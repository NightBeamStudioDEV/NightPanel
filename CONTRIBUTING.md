# Contributing to NightPanel

1. Create a focused branch from `main`.
2. Keep TypeScript strict and Rust warnings clean.
3. Update public protocol fixtures whenever a wire shape changes.
4. Do not add telemetry, cloud accounts, arbitrary console commands, secrets, private NightWatch source, or machine-specific paths.
5. Run `npm test`, `npm run lint`, `npm run build`, `cargo fmt --check`, and `cargo check` before opening a pull request.
6. Use GitHub private vulnerability reporting for security issues.

Contributions are submitted under the Apache-2.0 license.
